## 0. Method / validity
- 1622 per-night search transit events (kind=transit, origin=search) on 12 nights; 2 origin='user' rows excluded. Groups: REJECTED 1171 (725 user-only, 446 also coincidence-vetoed), UNCONFIRMED 323 (+127 coincidence-vetoed), WASP-145 A b (det 5494) 1.
- Production search inputs rebuilt from night_lc.npz + ref.npz (decorrelated lc, comparison-star CBVs, frame error scale, production SearchSettings from the npz config). `search_one_star` reproduces snr and tc of 1622/1622 DB events exactly (|dsnr|<1e-3).
- Proposed fit (fitlib.py): trapezoid (tc, T14, f free; f in [0.01,0.5]) + simultaneous poly2 + 3 CBV nuisance (variable projection, global grid + multistart refinement); competing models with the same nuisance: flat, best step, best ramp, box (f=0.01), V (f=0.5), asymmetric trapezoid, poly+2 baseline; BIC uses chi2 scaled by max(1,chi2_red). Extra decorrelation test: refit with per-star FWHM ratio, background, centroid x, y regressors.
- Injection: 80750 injections (8 T80S nights x 10000 + ROBO43 750; 75 % limb-darkened quadratic LD straight-path, 25 % trapezoid f 0.05-0.5; depth log-uniform 0.5-5 %, T14 U(0.5,3) h, tc uniform over the whole night so 74 % are partial, b U(0,0.85)); stars: searched, non-comparison, instrumental mag <= -9.6, half clean (fr3<0.05, fr6<0.10, not blended) half blended (Gaia flux ratio within 3" > 0.2 or relphot blended flag), half rms<1.5 % / half >=1.5 %. Injected into the decorrelated LC of all apertures, then production `search_one_star` + the same flag logic (APERTURE_INCONSISTENT, NEIGHBOUR_BLEND, hard flags). "Recovered" = candidate (snr>=6, no hard flag) with |tc-tc_inj| <= max(T14, found dur)/2+0.01 d. 5450 recovered (4924 T80S + 526 ROBO43).
- NOT injectable: SHARED_EPOCH, ON_VARIABLE, coincidence veto (population/catalogue level) -> their recall is reported NaN.

- Runtime 25 ms/event median (p95 62 ms; whole feature set 30-60 ms) vs 2.7 ms for the current fit; scipy success 99.9 % (injections) / 99.7 % (events); current stored fit converged on 90 % of the same 1330 events (REJ 99.7 %, UNC 42 %).

Partial events: T14 within 30 % in 53 % (current 48 %, with 90 % flagged lower limit). Shallow (0.5-1 %) detected events are biased deep (median 2.85x, selection).
- Degeneracies: median |corr(T14, f)| 0.76 (inj) / 0.81-0.84 (events), |corr(depth, constant baseline)| 0.72 / 0.65, |corr(depth, T14)| 0.35 / 0.24; Jacobian rank-deficient (cond > 1e8) in 29 % of injections and 58-67 % of events (ingress unresolved: ingress sampled by < 2 frames in 16 % of injections, 41-48 % of events; f at a bound in 5 % / 10 %). The nuisance model (poly2+3 CBV) shortens the fitted T14 by ~3-6 % and, for WASP-145 A b, to 0.44x of literature.
- Baseline choice (poly0/1/2, with/without CBV) changes dBIC by up to 2-3x for every population equally and does not change which events pass dBIC>=10 (REJ 92-93 %, inj 99 %).

## G. Recommendation and caveats
Recommended (R90): top1_share <= 0.4 & top3_share <= 0.6 & seeing/bkg/centroid-regressor depth ratio >= 0.7 & dchi2 retention >= 0.3 & 3-sigma-clip dchi2 >= 16 & dBIC_flat >= 6 & fit success; removes 67 % of REJECTED (63 % of those not already coincidence-vetoed) and 74 % of UNCONFIRMED at 91 % recall (90 % SNR-matched; 94 % for fully-inside events; 63 % removal when thresholds are chosen on other nights). Add the flipper veto where >= 30 frames exist. Shape cuts (step/ramp/box/ingress fraction) and "T14<=span with both-side coverage" cost 30-45 points of recall for 10-20 more points of FP removal and fail WASP-145 A b (box/ingress) — report them as flags/ranks, not hard cuts.
Caveats: (1) labels: REJECTED are visual judgements (65 % "Systematics. Noise"), UNCONFIRMED is a mix; 33 % of REJECTED still pass R90 and several look like clean U-shaped events (e.g. det 81183, 1.9 %, 1.0 h) — the cuts cannot reproduce those verdicts. (2) Only one real transit (WASP-145 A b, 30 s cadence, different instrument); T80S real-planet behaviour inferred from injections whose depth (0.5-5 %), T14 (0.5-3 h), LD shape and star sample are my choice; recall for depth > 5 % is untested. (3) Thresholds were chosen on the same events (a 5-night/7-night split loses ~4 points of FP removal). (4) Injections recover only 6.7 % of events; most recall is for rms<1.5 % stars. (5) The regressor test uses real per-star FWHM/background/centroid; it rewards injection recall because injections do not correlate with them, and a real transit coincident with a seeing change would be penalised. (6) Not tested: nights 16-18 (27 frames; no flip stats, no injection), SHARED_EPOCH/coincidence veto, ON_VARIABLE, Gaia radius/Teff density limit (only rho_max=5 g/cc), photometry items, nights after 20251207, the DB's "UNCONFIRMED" truth.
